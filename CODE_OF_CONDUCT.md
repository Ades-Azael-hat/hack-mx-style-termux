# Código de Conducta

Este proyecto adopta el Código de Conducta del Colaborador (Contributor Covenant). Se espera que todos los colaboradores mantengan un comportamiento respetuoso y profesional.

Resumen rápido:
- Sé respetuoso y considerado con los demás.
- No toleramos acoso, discriminación ni lenguaje ofensivo.
- Los reportes de mala conducta se deben enviar por correo electrónico a: bochmen3@gmail.com

Si quieres leer la versión completa del Contributor Covenant, puedes visitar: https://www.contributor-covenant.org/es/version/2/0/code_of_conduct/
